# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Delegated by brief: plain static HTML, CSS and JavaScript with locally vendored Three.js. No paid services.
## Users
Assumption under delegated concept freedom: curious adults exploring a tactile fictional material laboratory.
## Product Purpose
Soft Orchard is an original fictional jelly-fruit playground. Success is being able to add, deform, cut and stack procedural fruit.
## Capabilities and Constraints
Follow Marina Budarina's freely available Jelly Study staged prompt. Static GitHub Pages; desktop and 390px mobile; reduced motion; no signup; no external user data. All fruit is synthetic geometry. No claims of scientific accuracy.
## Brand Commitments
Source-pinned warm off-white, charcoal, Outfit Bold, text behind volumetric pear, centered add controls and bottom toolbar. Original name and copy.
## Evidence on Hand
Read original source https://budarina.design/prompts on 2026-11-09. Eight freely accessible Vibe-code prompts compared; Jelly Study is the most ambitious, with seven progressive stages. Copy buttons require no login. No source collection redistributed.
## Accessibility & Inclusion
Keyboard-operable controls, visible focus, touch targets, reduced-motion default pause and honest WebGL fallback.
